# Source, communication and review scope

## Exact original distribution

- Nexus mod: **234** — ASTRONEER Mod Framework.
- Nexus file: **1167** — Universal Manager **1.0.2**.
- Original archive SHA-256: `c792b980cec93db48e0e77d656e5542c06cab810c14884135ff6e6f2be335fe8`.
- Original shipped EXE/DLL identities: [source-binding.json](../source-binding.json).

The Nexus page was prepared as a draft. This source publication neither publishes that page nor changes its download package. A source link or a successful rebuild is not proof of Nexus approval.

## Authored native compilation closure

The repository includes the original C++ translation units, compiler-consumed authored headers, public trust anchors, generated public manifest headers, Win32 resource source and icon used for the shared framework. Their bytes are checked against original build records before publication. Unused gameplay-specific headers present in an earlier review collection are not published; no required original authored Core compilation input is omitted.

The additional portable driver, documentation, source manifest and sanitized verification evidence are publication tooling, not changes to production C++ implementation.

Some common contracts contain module identifiers or compatibility data. These are necessary framework interfaces, not the independent Planet Flattening, Universal Slot or Wide Range gameplay implementations. Those modules' DLLs and entry-point sources are excluded.

## Third-party loader

The original package includes `UE4SS.dll` and the `dwmapi.dll` loader proxy. Those are third-party release members, not authored binaries rebuilt by this recipe. Their exact hashes are listed alongside the authored binaries. Upstream source, version and build documentation are supplied in [BUILD_INSTRUCTIONS.txt](../BUILD_INSTRUCTIONS.txt).

`src/core/UE4SS.def` is an import definition derived from that loader's exported symbol table. The build recreates an import library locally; it does not redistribute a proprietary SDK or create a replacement loader.

## Cooked UI data

The original support-card `.pak` has SHA-256 `0e9d37ae18216cb9cee939ea63e1e4bedfb49460b64ebfdcac346a1ff0e51ec2`. Its contents are the `M_Card` material and `T_Artwork`, `T_Back`, `T_Mask`, `T_QrAfdian`, `T_QrQQ`, `T_Subject` and `T_TextLayer` textures, in cooked `.uasset`/`.uexp` form.

This pack remains in the original distribution and is not redistributed or regenerated by this native-source build. The published native support-card/menu behavior is in `src/core/shared/native_runtime/`. Compiling the native code is not a complete cooked-art reconstruction.

## Local communication and optional links

Installation, locally downloaded updates, removal and signature verification operate on local files. The authored framework and manager use file-based commands and state, including `request.json` and `runtime-state.json`; these are not server requests.

The unchanged source includes user-initiated external link actions:

- The manager's QQ community/group link.
- The in-game More Mods link: https://mod.cab
- The in-game Afdian/support link: https://afdian.com/a/Youtiaowei

These links are not required for installation or gameplay. No real local pairing record, production credential or player configuration is included.

## Evidence limits

The public snapshot is exercised by a fresh isolated native compile/link run. Its [sanitized receipt](BUILD_VERIFICATION.json) binds the targets and tested tooling; raw local build logs are not published.

A native compile/link pass does **not** establish byte-identical production reconstruction, a fresh live-game acceptance, a full upstream-loader security audit, offline network testing or Nexus safety approval. The build does not install into a game, launch the game, touch saves, change private signing authority or generate production release signatures.
